Overview & Field Approach

Independent libraries require a flexible, personalized operational management approach compared to public libraries. For this project, our team collaborated closely with the owner of Howl Library through in-depth interviews and field research to analyze daily operational bottlenecks and design a tailored system solution.

Three Core System Modules

The management system was engineered around three primary modules to streamline daily library activities:

  • Reservation Module: Calculates room capacity in real time, supporting online reservations, group orders, and walk-in visitors. It also integrates with external printers to generate wristband access labels.
  • Membership Module: Integrates NFC/QR Code keyrings with a multi-tiered membership system (Regular, Member, and Howl Crew). The system automates book borrowing limits, discount validations, and monthly attendance tracking.
  • Book Circulation Module: Features a centralized dashboard for accurate book inventory monitoring, tracking availability statuses, transaction histories, and loan durations.

Database Architecture

Beyond interface design, this project focuses on building a robust data foundation through Conceptual Database ERD, Logical Database, and Physical Database ERD phases, alongside executing SQL queries for efficient operational transaction management.
