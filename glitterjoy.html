Overview & Background

Glitter Joy was developed to resolve operational inefficiencies in the game console rental system (PlayStation & Nintendo). Conventional processes often led to issues such as unconfirmed unit availability, inaccurate cost calculations, and double-booking risks. To address these challenges, Glitter Joy was built as a hosted, independent web platform that digitizes and automates the reservation workflow in real time.

System Mechanism & Workflow

The platform provides complete transparency, allowing prospective renters to view available time slots instantly. Once the user selects a unit, date, and rental duration, the system automatically calculates the total cost. To secure reservations, users are given a 10-minute window to validate their payment by uploading proof of transfer via WhatsApp. Upon verification by the admin, the slot status in the database automatically updates to booked.

System Analysis Approach

In addition to full-stack web development, this project includes a comprehensive Software Requirements Specification (SRS) document. This document details functional and non-functional requirements as well as data flow modeling, serving as a structured application of software engineering principles.
